# Methods

We formulate frame-level guitar tablature estimation as a structured multi-class prediction problem. For each short audio context window, the model predicts one categorical state for each of the six guitar strings. Each string has 21 possible states: one non-sounding state and 20 fret positions. This formulation imposes a useful inductive bias. Rather than treating tablature as an unconstrained symbolic sequence, the model predicts directly in an instrument-aware output space that reflects the physical structure of the guitar. At the same time, the prediction problem remains challenging because the mapping from audio to tablature is many-to-one at the pitch level: multiple string-fret combinations can produce the same pitch content.

The baseline architecture is a convolutional neural network operating on local constant-Q transform windows. The intuition behind this design is that short-range spectral patterns contain information about note onsets, harmonic structure, timbre, and neighboring context that are relevant for determining the active fret state on each string. Convolution is a natural choice because it exploits local stationarity in time-frequency representations and learns translation-tolerant filters that can detect musically meaningful structures such as harmonic stacks and transient energy. After several convolutional layers and pooling operations, the resulting feature map is flattened and projected into a six-by-twenty-one output tensor. A softmax is applied independently for each string, so the model produces six separate categorical distributions rather than one large joint distribution over all possible fretboard configurations. This decomposition is computationally efficient and matches the per-string labeling scheme, although it does not explicitly model cross-string constraints beyond what is captured implicitly in the shared hidden representation.

The recurrent extension augments the convolutional frontend with sequence modeling. The motivation is that local spectral evidence alone may be insufficient when notes are sustained, weakly articulated, or masked by other strings. In those cases, adjacent frames carry strong information about whether a string should continue sounding, transition to a new fret, or become silent. The CRNN therefore first extracts local features with convolution and then feeds a short learned sequence representation into a gated recurrent unit (GRU). The GRU is intended to summarize temporal continuity while retaining the ability to adapt to fast local changes. Early CRNN experiments used a larger bidirectional GRU, motivated by the idea that access to both past and future local context might improve disambiguation. Later experiments simplified this design to a smaller unidirectional GRU. This change reduced model capacity and made the temporal component easier to interpret as a modest extension of the convolutional baseline rather than a substantially different model family.

Training uses categorical supervision at the per-string level. Conceptually, the objective encourages the model to assign high probability to the correct fret state for each string in each frame. One complication is that the dataset is strongly imbalanced: the non-sounding class is much more common than active fret classes. In such a setting, unweighted optimization can favor a conservative strategy that predicts silence too often. This motivates the use of loss modifications that place greater emphasis on sounding-note prediction. In later CRNN configurations, an auxiliary sounding loss was added to explicitly separate the binary question of whether a string is active from the finer-grained question of which fret is active. The intuition is that this decomposes the task into two related subproblems: detecting note presence and then identifying position. Such auxiliary supervision can improve recall even when the full fret classification problem remains difficult.

This modeling choice also clarifies the distinction between pitch-level and tablature-level correctness. Because per-string classifications are converted into both a pitch set and a specific fretboard configuration, the same prediction can be partially correct in one sense and wrong in another. A model may recover the correct pitch content while assigning the note to the wrong string, especially in regions where multiple fingerings are acoustically plausible. For this reason, evaluation is performed with both pitch-based metrics and exact tablature metrics. Pitch precision, recall, and F1 measure whether the sounding notes are correct after collapsing across equivalent fingerings. Tablature precision, recall, and F1 require the model to recover the exact string-fret assignment. The tablature disambiguation rate further quantifies how often pitch-correct predictions are also position-correct. Together, these metrics separate the easier problem of note recovery from the harder problem of fingering recovery, which is the central challenge of audio-to-tablature transcription.
