# Abstract

Automatic guitar transcription is challenging because the system must recover not only pitch content but also the string and fret configuration that defines a valid tablature representation. This project reproduces and extends the TabCNN approach for frame-level tablature estimation on GuitarSet using constant-Q spectral inputs. The work progressed through several phases: modernization of the original training pipeline, diagnosis of an early class-collapse failure mode, initial CRNN experiments with a larger bidirectional GRU, and a later stabilized comparison using a smaller unidirectional GRU. After resolving the most severe training issues, the recurrent model achieved stronger pitch-level performance, reaching pitch F1 up to 0.8416, while the CNN remained competitive or better on stricter tablature-oriented metrics such as tablature F1 and tablature disambiguation rate. These results indicate that temporal context improves note recovery, but exact fingering prediction remains difficult and is not solved by recurrence alone. More broadly, the project shows that implementation details and optimization behavior materially affect conclusions in this imbalanced transcription setting.
