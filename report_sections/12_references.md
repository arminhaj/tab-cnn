# References

The reference list should include the original TabCNN paper and repository, the GuitarSet dataset paper, and any core papers on automatic music transcription or sequence modeling that are cited in the background and methods sections.

At minimum, include entries for:

- The original "Guitar Tablature Estimation with a Convolutional Neural Network" paper
- The GuitarSet dataset paper
- Any cited work on convolutional or recurrent neural networks for music transcription
- Any additional sources used to justify evaluation metrics or sequence modeling choices

If the final report discusses modernization issues or implementation regressions, those should be described as part of the project analysis rather than cited as external references unless a published source is used.
